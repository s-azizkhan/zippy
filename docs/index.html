How it works

You write the ticket. Agents do the work. You sign off.

Declare intent

Write a ticket, sync one from Linear, or file it from your terminal.

Agents work

Claude Code runs over ACP in an isolated worktree. Pipelines hand off between roles.

Pipelines

A team of role agents, wired like a real review process.

Each agent has its own prompt, model and permissions. Chain them with routing rules, or pull one in with an @mention.

Install

Running in two minutes.

Clone, install, open the board. Agents use the Claude Code account you're already signed in to.

Node 22+ and pnpm
PostgreSQL (the desktop app bundles one)
claude, git and gh CLIs
macOS for the desktop app; web app runs anywhere
# clone and run
git clone https://github.com/s-azizkhan/zippy.git
cd zippy && cp .env.example .env
pnpm install
pnpm db:push
pnpm dev   # → http://localhost:5199
# once
pnpm link --global

# from any repo
zippy "fix login redirect"
pytest 2>&1 | zippy "fix failing tests"
# needs Rust
pnpm desktop                       # dev
pnpm --filter @zippy/desktop build # .dmg, Apple Silicon
FAQ

Questions

Is Zippy free?

Yes. Zippy is open source under the MIT license. If it saves you time, you can sponsor it on GitHub.

Do I need an Anthropic API key?

No. Zippy runs your local Claude Code CLI with the account you're already signed in to. Nothing is stored or sent anywhere else.

How is it different from Vibe Kanban, Conductor or Claude Squad?

Those focus on running agents in parallel. Zippy is built around tickets and review: Linear sync, multi-agent pipelines, a review inbox with decision cards, quick capture and an MCP hub, all on your machine.

Will agents touch my working copy?

No. Every ticket gets its own git worktree and branch. You review the diff before anything is merged or pushed.

Which platforms are supported?

The desktop app is macOS on Apple Silicon. The web app runs anywhere Node and Postgres run, and you can reach it from your phone over a private tunnel.
